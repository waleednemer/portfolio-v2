موقع Portfolio متكامل لمهندس مدني
=================================

التقنيات:
- HTML5
- CSS3 (Responsive Design + Dark Mode)
- Vanilla JavaScript

تشغيل الموقع:
1. فك ضغط civil_engineer_complete.zip.
2. افتح index.html مباشرة في متصفح حديث.
3. يلزم اتصال بالإنترنت لتحميل خط Cairo/Inter والصور الخارجية.

ملاحظة مهنية:
لا تضع شهادات أو مشاريع أو خبرات غير حقيقية، ولا تنشر صوراً أو معلومات سرية تخص العملاء أو جهات العمل.

النشر:
يمكن رفع الملفات على GitHub Pages أو Netlify أو أي استضافة Static Hosting. ارفع محتويات المجلد كما هي، واجعل index.html في المجلد الرئيسي.
